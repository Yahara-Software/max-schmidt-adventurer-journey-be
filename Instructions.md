# Instructions for Program Users

### Design Decisions Overview

Although this idea could be implemented in a number of ways, I chose to do so using a C# command line app. 
This choice was intentional, allowing an all-in-one user experience and fun interaction rather than building out an API that could be called to achieve the same result.
In a true backend, this API system would implement services and classes similar to those in my program, abstracting the deeper implementations and method calls behind a simple interface, similar to how I tried to write the main method as a sort of controller.

### Starting the App

After cloning the GitHub repository onto your local machine, locate the following file path using your file explorer app:

- Mac Users: `/AdventurerPath/bin/Release/net10.0/osx-x64/publish/AdventurerPath`
- Windows Users: `\AdventurerPath\bin\Release\net10.0\win-x64\AdventurerPath.exe`

In double clicking on this executable file, the system's console should open. The app will automatically start up and provide further instructions.
